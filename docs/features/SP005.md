# SP005 — Log kaydı

Durum: ✅
Task: [T005_0](../tasks/T005_0.md)

## Amaç

Agent'ın kanıt toplayabilmesi için loglar sorgulanabilir bir yerde durmalı.

## İsterler

- Uygulama logları correlation id ile birlikte kalıcı olarak saklanmalı.
- **Veritabanı sorguları da loglanmalı.** Her iki analiz senaryosunun tüm kanıtı
  bu satırlardan geliyor; bu kapalıysa proje çalışmaz.
- Correlation id'ye göre erişim hızlı olmalı.
- Konsol logu geliştirici için çalışmaya devam etmeli.

## Kabul kriterleri

- [x] Bir istek sonrası o correlation id ile log satırları sorgulanabiliyor
- [x] Veritabanı sorgu satırları loglar arasında görünüyor
- [x] Correlation id ile erişim indexli
- [x] Konsol logu bozulmamış
