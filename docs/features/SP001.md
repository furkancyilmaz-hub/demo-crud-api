# SP001 — Domain iskeleti

Durum: ✅ yapıldı
Repo: demo-api

## Ne yapılacak

`Proposal`, `Customer`, `Payment` entity'leri, repository'leri, DTO'ları ve
controller'ları. (`entity/`, `service/`, `controller/`, `dto/`).

Aşağıdaki create scriptlerini dikkate alarak yapı iskeletini oluştur.
CREATE TABLE proposal (
id            BIGSERIAL PRIMARY KEY,
proposal_no   VARCHAR(30)   NOT NULL UNIQUE,
status        VARCHAR(20)   NOT NULL,   -- DRAFT | APPROVED | REJECTED
issue_date    DATE          NOT NULL,
total_premium NUMERIC(15,2)
);

CREATE TABLE customer (
id          BIGSERIAL PRIMARY KEY,
proposal_id BIGINT      NOT NULL REFERENCES proposal(id),
identity_no VARCHAR(20) NOT NULL,
full_name   VARCHAR(120) NOT NULL,
city        VARCHAR(40)  NOT NULL,
status      VARCHAR(20)  NOT NULL       -- ACTIVE | PASSIVE
);

CREATE TABLE payment (
id          BIGSERIAL PRIMARY KEY,
customer_id BIGINT        NOT NULL REFERENCES customer(id),
amount      NUMERIC(15,2) NOT NULL,
due_date    DATE          NOT NULL,
status      VARCHAR(20)   NOT NULL      -- PENDING | PAID | OVERDUE
);

## Kararlar

- **Bean Validation eklendi**: `spring-boot-starter-validation` yeni bağımlılık
  olarak eklendi; DTO'larda `@NotBlank`/`@NotNull`/`@Positive`/`@Digits` vb.
  kullanıldı.
- **Full CRUD**: Üç entity için de create/get/list(paged)/update/delete.
- **Sadece unit test**: Testcontainers/DB testi eklenmedi; service katmanı
  Mockito ile test edildi (`ProposalServiceTest`, `CustomerServiceTest`,
  `PaymentServiceTest`, `GlobalExceptionHandlerTest` — toplam 31 test).
- **Config düzeltmesi**: `spring.jpa.open-in-view: false` eklendi,
  `ddl-auto: update` → `ddl-auto: none` yapıldı. Migration/Flyway eklenmedi —
  şema bu SP'nin kapsamı dışında, DDL yukarıdaki script ile manuel
  oluşturulmalı.
- **`@OneToMany` koleksiyonu yok**: Proposal→Customer ve Customer→Payment
  ilişkileri tek yönlü `@ManyToOne(LAZY)` ile kuruldu (child tarafında).
  N+1 ve sınırsız koleksiyon riskini baştan kapatır.
- **Response DTO'ları flat**: Child koleksiyonlar embed edilmiyor; child
  veriye child'ın kendi paginated endpoint'i üzerinden (`?proposalId=`,
  `?customerId=` query param ile) erişiliyor.
- **FK alanları update'te immutable**: `proposalNo`, `proposalId`,
  `customerId` update DTO'larından hariç tutuldu (oluşturulduktan sonra
  değiştirilemez business key/FK).
- **404 vs 400 ayrımı**: URL path'teki `{id}` bulunamazsa `ResourceNotFoundException`
  (404); request body'de referans verilen parent yoksa
  `InvalidReferenceException` (400).
- **Silme engellenir, cascade edilmez**: Child kayıt varken parent silinmeye
  çalışılırsa `ResourceInUseException` (409).
- **Yeni `exception/` paketi**: CLAUDE.md'nin adlandırdığı 5 pakete dahil
  değil ama merkezi `@RestControllerAdvice` ve custom exception'lar için
  ayrı bir cross-cutting paket açıldı.
- **Bilinen sınırlama**: `DemoCrudApiApplicationTests` (`@SpringBootTest`)
  gerçek bir Postgres olmadan context yükleyemiyor (`ddl-auto: none` +
  gerçek datasource config). Bu SP'nin kapsamı dışında, dokunulmadı.
