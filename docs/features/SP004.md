# SP004 — İstek korelasyonu

Durum: ✅
Task: [T004_0](../tasks/T004_0.md)

## Amaç

Agent'ın bir isteğe ait logları bulabilmesi için her isteğin izlenebilir bir
kimliği olmalı.

## İsterler

- Her HTTP isteği benzersiz bir correlation id ile ilişkilendirilmeli.
- Bu kimlik cevapta çağırana geri dönmeli — agent onunla log arayacak.
- Çağıran kendi kimliğini gönderdiyse o korunmalı; agent isteği tekrar attığında
  kendi kimliğini basıyor.
- Kimlik istek bitiminde temizlenmeli, sonraki isteğe sızmamalı.

## Kabul kriterleri

- [x] Her cevapta correlation id header'ı var
- [x] Gönderilen kimlik korunuyor
- [x] Aynı bağlantıdan peş peşe iki istekte kimlikler farklı
