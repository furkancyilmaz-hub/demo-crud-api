# SP006 — Log sorgulama servisi

Durum: ✅
Task: [T006_0](../tasks/T006_0.md)

## Amaç

Agent loglara veritabanına bağlanmadan, servis üzerinden erişsin.

## İsterler

- Correlation id ile log satırları sorgulanabilmeli.
- Seviyeye göre filtrelenebilmeli (yalnızca hata satırları gibi).
- Dönen satır sayısı sınırlanabilmeli ve bir üst sınır olmalı — agent'ın token
  bütçesi kısıtlı, sınırsız çıktı kabul edilemez.
- Satırlar zaman sırasında dönmeli.

## Kabul kriterleri

- [x] Correlation id ile filtreleme çalışıyor
- [x] Seviye filtresi çalışıyor
- [x] Üst sınır aşılamıyor
- [x] Sonuçlar zaman sırasında
