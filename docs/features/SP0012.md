# SP0012 — Ek ister: şema metadata ucu

Durum: ✅
Task: [T0012_0](../tasks/T0012_0.md)

Bu bir **ek ister** dosyasıdır.

## Neden

Analiz uygulaması parent-child ilişkisini tahminle değil, veritabanının kendi
foreign key tanımlarıyla bulacak. Ama agent hedefin veritabanına bağlanmıyor —
bu bilgiyi servisin kendisi vermeli.

## İsterler

- Veritabanındaki foreign key ilişkileri sorgulanabilmeli.
- Her ilişki için: hangi tablonun hangi kolonu, hangi tablonun hangi kolonuna
  işaret ediyor.
- Bilgi veritabanının kendi metadata'sından gelmeli; kod içinde elle
  tanımlanmamalı — şema değişirse liste kendiliğinden güncellenmeli.
- Uç salt okunur olmalı.

## Kabul kriterleri

- [x] Foreign key listesi dönüyor
- [x] Bu şemada iki ilişki görünüyor (customer→proposal, payment→customer)
- [x] Liste kodda sabit değil, veritabanından geliyor
