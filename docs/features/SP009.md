# SP009 — Senaryo: eksik index

Durum: ✅
Task: [T009_0](../tasks/T009_0.md)

## Amaç

Agent'ın teşhis edeceği ikinci performans problemi. Birincisinden farklı bir kanıt
yolundan bulunmalı — bu senaryo sorgu planına, diğeri log tekrarına dayanıyor.

## İsterler

- Müşteri arama servisi indexlenmemiş bir kolon üzerinden filtrelemeli, tüm tabloyu
  taramalı.
- Problem, servis yeniden başlatılmadan açılıp kapatılabilmeli — demo akışı buna
  dayanıyor.
- Her iki senaryo da aynı kontrol noktasından yönetilebilmeli.
- **Bu kontrol agent'a açılmamalı.** Fix'i insan uygular; agent yalnızca önerir.
