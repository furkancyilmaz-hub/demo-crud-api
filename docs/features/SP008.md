# SP008 — Senaryo: N+1 sorgu

Durum: ✅
Task: [T008_0](../tasks/T008_0.md)

## Amaç

Agent'ın teşhis edeceği birinci performans problemi.

## İsterler

- Müşteri listeleme servisi, müşterileri ödemeleriyle birlikte dönerken her müşteri
  için ayrı sorgu çalıştırmalı — kasıtlı problem bu.
- Liste ~200 müşteri dönmeli.
- Problem açılıp kapatılabilir olmalı; kapalıyken servis doğru davranmalı.
- Yavaşlık gerçek veritabanı davranışından gelmeli. Yapay bekletme kullanılırsa
  ne sorgu planı ne log kanıtı oluşur, senaryo anlamsızlaşır.
- Problemin izi loglarda görünmeli: aynı sorgunun tekrar tekrar çalışması.

## Kabul kriterleri

- [x] Problem açıkken loglarda tekrar eden sorgu satırları var
- [x] Kapalıyken sorgu sayısı birkaç taneye iniyor
- [x] İki durumda da dönen veri aynı
- [x] Yanıt süresi farkı gözle görülür
