# SP007 — Sorgu planı servisi

Durum: ✅
Task: [T007_0](../tasks/T007_0.md)

## Amaç

Agent bir sorgunun neden yavaş olduğunu tahmin ederek değil, planına bakarak
söyleyebilsin.

## İsterler

- Verilen bir sorgunun çalışma planı alınabilmeli.
- Plan, üzerinde akıl yürütülebilecek yapıda dönmeli — düz metin değil.
- Plan gerçek çalışma verisi içermeli (tahmini değil, gerçekleşen).
- **Yalnızca okuma sorguları kabul edilmeli.** Plan alma işlemi sorguyu gerçekten
  çalıştırdığı için bu bir güvenlik sınırı; kısıt servisin kendisinde olmalı,
  çağırana güvenilmemeli.
- Uzun süren sorgu servisi kilitlememeli.

## Kabul kriterleri

- [x] Okuma sorgusu için yapılandırılmış plan dönüyor
- [x] Veri değiştiren veya şema değiştiren girdiler reddediliyor
- [x] Birden fazla ifade içeren girdi reddediliyor
- [x] Uzun süren sorgu kesiliyor
